## 执行约定

成功请求不重跑；失败保留记录。每批保存配置、原始结果、源码校验和完成状态，分析写入新目录，结论与局限写入文档。后处理失败从已有产物接续，例如成本重放完成后论文构建失败，只重跑 `build`。

硬件上限为两张 RTX8000、每张 48GB。按实时显存余量和任务归属选择可用卡，不抢占其他任务；温度只记录。共享资源耗时不能作独占性能比较。独立 CPU 任务按资源规划并行，推理任务使用可断开终端继续运行的后台入口，启动后核对进程和输出。

新增模型、K=10/P2、温度或推理模式扫描、新领域、人工标注和样本量扩张暂缓。原协议元数据保留的额外选项不自动执行。

若方法与简单基线等价，或成本收益只见于部分构造，应相应收缩论文主张。补齐结果后，再修订摘要、贡献、结果与结论，并完成作者信息和投稿材料。
