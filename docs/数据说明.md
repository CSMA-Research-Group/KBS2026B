# 数据与论文对应关系

四个证据包的统一读取位置为 `data/archives/`。CPU 和主语言包通过[共享链接](../data/README.md#原始数据下载)下载到本地，由 Git 忽略；Experiment H、S1 随仓库提供。`data/manifest.json` 记录下载链接、包的 SHA-256、成员数量和解包位置；`members.jsonl.gz` 记录每个实验文件的大小与哈希。解包时逐文件检查，不改变原记录。

| 数据包 | 主要内容 | 论文用途 |
| --- | --- | --- |
| `cpu.tar.gz` | 16,128 条原始结果、2,304 个规模实例、576 个物理参考及原始分析 CSV | CPU 成本表、构造分层表、成本分布图 |
| `language.tar.gz` | 1,872 个世界及公开输入、隐藏标签、逐目标物理检查、请求、派发和已保存响应 | 主校准表；后续主语言结果 |
| `experiment_h.tar.gz` | carrying、π=0.25 的 640 个世界及准备证据 | 后续 H 配对实验，当前没有推理结果 |
| `s1.tar.gz` | 128 测试世界、768 决策、1,152 请求及参考 | S1 汇总和三张决策矩阵，均为早期 oracle 接口结果 |

`data/verification_cost/` 保存 E5/E7 诊断和使用的校准阈值；`illustrations/` 保存示意图定义与 14,336 个 CPU 绘图点；`protocols/` 保存协议和推理环境；`models/` 保存模型文件哈希。`selection.json` 记录 S1 和成本阈值子集的筛选来源哈希及行号。

主语言共有 1,280 个主世界、16 个开发世界和 576 个配对诊断变体。配对变体属于同一冻结批次，单独分析，不增加独立主样本量。已保存响应为 Qwen 4,872 条、Gemma 5,472 条，其中也包含开发和配对诊断请求。

解包后的 `main/language/` 中，`public/` 为模型可见输入，`labels/` 含隐藏规格和语义集合，`reference/` 为物理参考，`checks/` 为逐目标检查，`ready/` 为准备收据。模型目录的 `responses/` 与 `dispatched/` 按请求 ID 关联。缺失响应不等于无效输出，不能直接计入错误率或弃答率。

CPU 按物理布局配对：同一布局的四种规模、七个方法不是独立样本。操作代理将记录的工作计数等权相加，排除几何缓存命中；它不等于壁钟时间或费用。

## 代码入口

| 位置 | 阅读重点 |
| --- | --- |
| `code/revision_20261022/` | `language_cases.py` 生成、`language_interface.py` 解释、`runtime_checks.py` 核验、`language_analysis.py` 校准、`cpu_suite.py` CPU 基准 |
| `code/key_validation/` | 搜索、证书、参考与决策审计 |
| `code/audit/` | 有理数校准、独立物理检查、共享证书、停止规则和 H 变换 |
| `code/project/` | 数据解包、表格复核、成本重放、绘图与构建 |
| `code/tests/` | 有限状态、差分、物理边界、H 变换和证据包完整性检查 |

其余早期命名的 Python 包是当前求解器实际导入的依赖。科学设置保持不变，模型位置改由 `KBS_QWEN_MODEL`、`KBS_GEMMA_MODEL` 指定；不用模型推理时无需设置。冻结来源和适配后的哈希见 `code/source_bindings.json`。

测试和保存结果重放用于核对实现，不能替代真实模型实验或证明外部泛化。单颜色场景是冻结物理参考的已知边界，测试中保留该限制；修复需另行冻结和验证。
